# PDF to Markdown

Tools from the `pdftools` folder of [phelluy/llmtools](https://github.com/phelluy/llmtools/tree/main/pdftools).

**Local path:** à la racine du dépôt `llmtools`, dossier `pdftools/` (frère du dossier `skills/`).

## Prerequisites

If no `.venv` exists in the working directory, create one first:

```bash
uv venv
uv pip install pymupdf requests
```

- `pymupdf` — PDF → images conversion, raw text extraction
- `requests` — HTTP API calls

## Available tools

### 1. Mistral OCR to Markdown (`mistral-pdf2md.py`)

Converts a PDF to Markdown via the Mistral OCR API. Fast, extracts images as real files.

```bash
export MISTRAL_API_KEY="your-api-key"
uv run mistral-pdf2md.py <directory>
```

**Output:** `<name>.md` + `<name>_images/` folder with extracted images.

**Notes:**
- Processes all PDFs in the directory recursively
- Skips PDFs that already have a `.md` file
- No resume capability — if interrupted, re-run from scratch

### 2. UNISTRA Qwen to Markdown (`unistra-pdf2md.py`)

Converts a PDF to Markdown via the UNISTRA Qwen API (model `qwen3`). Incremental page-by-page approach with context from previous pages. Images are **described textually** in the markdown (short alt text + detailed italic description).

**Key features:**
- **Resume**: if the `.md` already exists, only missing or failed pages are reprocessed
- **Incremental write**: each page is saved as soon as it is processed (no data loss on interruption)
- **Retry**: 2 attempts per page if `<markdown>` tags are missing
- **Optimized context**: only the last 5 pages + a summary are sent to the LLM (avoids context overflow on long documents)
- **Metadata**: HTML comments `<!-- Page X/N : OK/ÉCHEC -->` in the `.md` for tracking

```bash
export UNISTRA_API_KEY="your-api-key"

# Single file
uv run unistra-pdf2md.py document.pdf

# Directory (recursive)
uv run unistra-pdf2md.py ./documents/

# Custom timeout per page (default: 600s)
uv run unistra-pdf2md.py document.pdf --timeout 120

# Force full re-conversion
uv run unistra-pdf2md.py document.pdf --force
```

**Output:** `<name>.md` + `<name>_images/` folder (reserved for future extraction).

**Resume example:**

```bash
# First run interrupted → pages 1-8 extracted, crash on page 9
uv run unistra-pdf2md.py document.pdf

# Second run → automatically resumes from page 9
uv run unistra-pdf2md.py document.pdf
```

### 3. Extraction verification (`check-extraction.py`)

Compares raw text extracted from the PDF (PyMuPDF `page.get_text()`) with the markdown content generated by `unistra-pdf2md.py`. Detects **major hallucinations** (massive divergences between actual text and LLM extraction).

**Metric:** Jaccard coefficient per page. A page is flagged if its score is below the threshold (default: 0.3).

```bash
# Verify with the .md corresponding to the PDF
uv run check-extraction.py document.pdf

# Custom threshold
uv run check-extraction.py document.pdf --threshold 0.5

# Different .md file
uv run check-extraction.py document.pdf --md other_file.md
```

**Example output:**

```
[info] 14 page(s) dans le PDF
[info] 14 page(s) OK dans le .md

  Page   1/14 : OK       Jaccard=0.864  brut=272  extrait=235
  ...
  Page   4/14 : FAIBLE   Jaccard=0.004  brut=346  extrait=8

─── Compte rendu ───
  Pages analysées : 14
  Pages OK        : 13
  Alertes         : 1
  Pages à vérifier :
    Page   4 : FAIBLE  (Jaccard=0.004)
```

**Limitations:**
- Only works if the PDF has **selectable text** (native PDF, not a scan)
- Does not detect fine-grained errors (proper nouns, numbers) — focus on massive divergences

## Comparison

| Feature | Mistral | UNISTRA |
|---|---|---|
| Image extraction | Yes (real files) | No (textual descriptions) |
| OCR | Yes | Yes |
| Scanned PDFs | Excellent | Excellent |
| Resume after interruption | No | Yes |
| Automatic retry | No | Yes (2 attempts) |
| Tracking metadata | No | Yes (HTML comments) |
| Cost | Paid API | Paid API |

## Usage guidance

- For **quick conversion with real images**: use `mistral-pdf2md.py`
- For **long documents, resumable conversion, or when images don't need to be extracted as files**: use `unistra-pdf2md.py`
- After any UNISTRA conversion, run `check-extraction.py` to verify quality
- Both tools require their respective API key in the environment (`MISTRAL_API_KEY` or `UNISTRA_API_KEY`)
